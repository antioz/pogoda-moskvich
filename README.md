# Погода для москвичей

Telegram-бот [@mscwthr_bot](https://t.me/mscwthr_bot), который раз в день постит прогноз по Москве голосом уставшего москвича: «блиииин жарко жесть +30», «блиин опять дождь +14», «блиииин похоолодало +6».

**Саморегистрирующийся**: любой добавляет бота в любую группу/канал (или жмёт `/start` в личке) — и тот сам начинает слать туда погоду. Без участия владельца.

## Как работает

Постоянный процесс `server.js` на VPS:

```
server.js (24/7)
 ├─ long-poll getUpdates ──→ мгновенно ловит «бота добавили» и /start,
 │                            пишет chat_id в data/state.json
 └─ планировщик 07:00 МСК ──→ Open-Meteo → фраза → рассылка во ВСЕ чаты
```

Состояние (список чатов + offset getUpdates) хранится в `data/state.json` (bind-mount, переживает рестарт контейнера). Зависимостей нет — только Node ≥20.

### Компоненты

| Файл | Назначение |
|---|---|
| `server.js` | постоянный процесс: long-poll + ежедневный планировщик (VPS) |
| `src/core.js` | общая логика: обработка апдейтов + рассылка |
| `src/tg.js` | транспорт к Bot API с авто-пином живого IP (обход РКН) |
| `src/weather.js` | погода по Москве из [Open-Meteo](https://open-meteo.com), без ключа |
| `src/phrases.js` | генератор «блиииин»-фразы по WMO-коду и температуре |
| `src/telegram.js` | sendMessage |
| `src/store.js` | чтение/запись `data/state.json` |
| `bot.js`, `src/poll.js` | разовые обёртки (рассылка / опрос) — для ручного запуска и Actions |

### Обход блокировки Telegram на российском VPS

На Timeweb-VPS РКН душит часть IP `api.telegram.org`, DNS отдаёт мёртвый адрес, IPv6 без аплинка. `src/tg.js` коннектится напрямую на живой IP (перебирает кандидатов, закрепляет рабочий), проверяя TLS по имени через SNI. На обычной среде (DNS живой) пин не задействуется.

## Деплой (VPS, Docker)

```bash
# на сервере, в каталоге проекта:
docker build -t pogoda-moskvich .
docker run -d --name pogoda-moskvich --restart unless-stopped \
  -e BOT_TOKEN=<токен от @BotFather> \
  -v $PWD/data:/app/data \
  pogoda-moskvich
docker logs -f pogoda-moskvich
```

Боту нужен только `BOT_TOKEN`. Список чатов он ведёт сам в `data/state.json`.

## Что нужно

1. В [@BotFather](https://t.me/BotFather) у бота включено **Allow Groups** (по умолчанию да).
2. В канал бота добавляют **админом** (право публикации); в группу — обычным участником.

Дальше — ничего. Любой добавляет бота куда угодно, бот мгновенно регистрирует и шлёт приветствие, а в 07:00 МСК идёт ежедневная рассылка.

## Локальный запуск / отладка

```bash
export BOT_TOKEN=...
node bot.js --dry-run    # показать погоду и пример фразы, без отправки
node server.js           # постоянный процесс (long-poll + планировщик)
```

## Изменить время поста

`server.js`, функция `msUntilNext0400UTC` — 04:00 UTC = 07:00 МСК.
